# 中文跟打器 Fcitx5 IME 兼容补偿

<p align="center">
  <img src="https://raw.githubusercontent.com/bingo084/typing-ime-fix/main/assets/icon.png" width="128" alt="中文跟打器 Fcitx5 IME 兼容补偿图标">
</p>

用于修复 Linux 下 Fcitx5/Rime 整句输入时，浏览器跟打器无法正确获取物理 `keydown` 所造成的问题。

## 支持站点

- 虎码官网「健康练习」
- 木易跟打器 Web 版

## 功能

- 根据 `compositionupdate` 补偿被浏览器隐藏的击键事件。
- 已收到真实击键时进行匹配，避免重复计数。
- 修复虎码健康练习中的击键和码长漏记。
- 修复木易跟打器整句上屏后不自动完成的问题。
- 不发送网络请求，不收集或上传任何数据。

## 使用方法

安装脚本后刷新受支持的跟打页面即可，无需配置。

如需查看当前页面的诊断统计，可打开浏览器开发者工具，在控制台输入：

```js
__typingImeFix
```

## 限制

浏览器无法暴露的物理按键只能根据输入法合成事件推算，因此无法识别每个缺失按键的具体键位。虎码整句在组句时预编辑文本可能缩短，所以脚本会将每次未匹配真实按键的合成更新计为一次击键；若 Backspace 也被浏览器完全隐藏，可能产生少量误差。

## 隐私

脚本完全在浏览器本地运行，没有统计上报、广告、追踪或外部依赖。
